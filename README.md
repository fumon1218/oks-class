# ok's class — 옥쌤의 즐거운 교실

특수교육대상학생(자폐, 지적장애, 발달장애 등)을 위한 초·중·고 교육과정(2022 개정) 기반 교육 앱입니다.
(강원특수교육원 홍보 게임 '정글 점프'와는 별개의 수업용 앱이에요.)

## 우주 지도 (첫 화면)
- 우주선을 타고 교과 별로 떠나요: **모두가 빛나는 별**(국어·영어·복습 모험장·미니게임·내 방) · **바다별**(음악·미술) · **사랑별**(수학·과학) · **꿈별**(사회·진로직업·일터 거리) · **햇살 농장**(여러 교과 함께) · 아직 태어나지 않은 별(새 교과·심화 단원 자리)
- 별 위 건물을 누르면 층(1층 초등 · 2층 중등 · 3층 고등)별 차시와 수준 1~5가 바로 나와요. 차시를 마치면 그 건물로 돌아와요
- 복습 모험장: 최근 한 차시와 다음 수준 추천 (별 3개면 다음 수준, 아니면 같은 수준 한 번 더)
- `space/` (지도·건물 배정 `space/data.js`), 예전 첫 화면은 `classic.html`
- 3D 별: `art/3d/*.glb` (AI 도구로 만든 무거운 GLB를 `python3 scripts/import_3d.py <입력.glb> <이름> [삼각형 수]`로 1MB 안팎으로 줄임 — 질감 이음매를 지키는 줄이기 `scripts/simplify.c`), 그리는 곳은 `core/oks-3d.js`(외부 라이브러리 없는 WebGL). '움직임 줄이기'·저사양 기기는 그림 그대로. 한 파일에 여러 물건이면 `--split <입력.glb> 이름1,이름2,...`로 나눔
- 3D 크게 보기(`OKS3D.open`): 끌어서 위아래·좌우 돌리기, 휠·두 손가락으로 확대·축소, 두 손가락·오른쪽 버튼으로 옮기기, 처음으로. 우주 지도 별의 🔍, 별 위 '3D로 보기', 건물 안 그림, 차시 카드의 '3D' 단추에서 열려요
- 그림: `scripts/art_manifest.py` 목록 → `docs/image-prompts.html` 작업판 → 받은 그림은 `python3 scripts/import_art.py <폴더|zip>` (배경 지우기·여러 개 한 장 자르기 자동). 그림 사전에 있는 이모지는 차시 카드에서 그림으로 바뀌어요

- **교과**: 국어·수학·사회·과학·영어·미술·음악 7교과 × 초·중·고 × 3단원 × 2차시 = 126차시 (`curriculum/source/*.xlsx`)
- **수준 5단계**: 1 감각 탐색 → 2 골라 보기 → 3 직접 해 보기 → 4 혼자 해 보기 → 5 생활에 써 보기
- **지금 열린 게임**: 초·중·고 126차시 × 5수준 모두 (초등 `play/content.js`, 중·고등 `play/content2.js`)
- **문항**: 차시마다 기본 8문항 이상 · 생활 적용(5수준) 5문항 이상(`play/content-extra.js`), 판마다 순서를 섞어 반복을 줄임
- **선생님 문항 편집** (`curriculum/editor.html`): 차시별로 문항 추가·기본 문항 숨기기·선생님 문항만 쓰기, 📷 우리 학교 사진·이름 카드, 파일로 내보내기/불러오기
- **교사용 지도 계획서**: `curriculum/plan.html` — 교과→학교급→단원→차시별 학습 목표·게임 공간·수준별 게임 활동(설계표 원문 대조)·평가 기록·연계 가게, 인쇄 가능
- **접근성**: 탭·끌기 둘 다 가능, 음성 안내, 반짝임 → 손가락 촉진(1~3수준 자동, 4~5수준은 🙋 도와줘), 시간 제한 없음, 움직임 줄이기, 큰 누름 칸
- **기록**: 수준·틀림·힌트·도와줘·시간 + 도움 정도(독립/언어힌트/시각힌트/시범/신체지원) → 배움 지도 📋 기록에서 CSV 저장
- **학생 프로필(익명)**: 배움 지도 위쪽 👤에서 별명·번호로 학생을 만들고 고르면 기록·별·수준이 학생별로 따로 저장돼요(이름 쓰지 않기, 이 기기 안에만 저장). 고르지 않으면 '공용'으로 예전처럼 기록돼요. 기록 화면·CSV는 선택한 학생 것만 나옵니다. 감각 설정(소리·움직임 줄이기 등)은 기기 공통입니다. (`core/oks-core.js`의 `OKS.profile`)
- **미술 성취기준 연결**: 교사용 지도 계획서(`curriculum/plan.html`)에서 미술 18차시마다 2022 개정 기본 교육과정 성취기준과 평가 준거를 보여 줘요(`curriculum/art-standards.js`, 연결·준거는 제안이며 고시 아님)

## 게임 모드 (정글 점프 방식)
- **코인 · 레벨 · 오늘의 미션 · 배지** (`core/oks-eco.js`): 차시 게임과 가게 영업에서 코인과 경험치를 받아요. 레벨 2에 춘천본원, 레벨 3에 원주분원이 열려요 (설정 → 모든 마을 열기)
- **마을과 버스** (`town/`): 🚌 버스로 강릉분원 → 춘천본원(이해·보조공학실, 진로직업 공방, 체험마을) → 원주분원(스마트팜, 분식집, 분리수거장, 뷰티숍, 드론장)
- **가게 영업(타이쿤)** (`shop/`): 손님 입장 → 인사 → 주문(그림·소리) → 작업대 순서(고르기·세어 담기·순서·꾹 누르기·타이밍·문지르기·톡톡·기다리기·나누기·규칙·드론·스위치) → 드리기 → 돈 받기 → 팁 코인. 단골손님, 오늘의 특별 손님(고릴라 대장), 가게 꾸미기
  - 춘천: 친구 돕기 · 스위치 체험 · 염색 · 목공 · 포장 · 구슬 공예 / 원주: 스마트팜 · 분식집 · 분리수거 · 드론 배달 · 뷰티숍 / 강릉: 영어 스낵 바
  - 가게마다 연계 차시가 있어 배움 지도와 차시 끝 화면에서 바로 이어져요. 수준 1~5가 그대로 적용돼요
- **🔘 스위치(스캔) 모드**: 설정에서 켜면 누를 수 있는 것을 불빛이 차례로 비추고, 큰 스위치·스페이스·엔터 하나로 골라요

## 차시 게임 구조
- `learn/` 배움 지도(교과 → 학교급 → 차시 → 수준), `play/?id=<활동ID>&level=1~5` 차시 실행
- `core/` 공통 틀(햇살 농장 온실 배경, 버튼·별·손가락 그림, 목소리·효과음·촉진·기록)
- `play/engines.js` 고르기·짝 찾기·나누어 담기·순서·규칙 기차·수 세기, `play/engines2.js` 리듬·힘 게이지·색 섞기·길 찾기·선 긋기·도형 만들기·미술실 연결, `play/farm.js` 햇살 농장
- `play/content.js` 차시별 소재표 — 중·고등 차시는 여기에 추가하면 바로 열립니다
- 엑셀을 고친 뒤: `python3 scripts/build_lessons.py` → `python3 scripts/build_sw.py` → `node scripts/smoke-test.mjs`

## 온라인으로 쓰기
### 씽씽별 육상 모험
- `sports/?festival=summer&sport=athletics`: 초·중·고 각 3차시, 수준 1~5. 차시 목표에 따라 준비·신호 반응·이동·속도/멈춤·장애물·차례 전달·마무리를 조합합니다.
- 기본은 큰 버튼 하나이며 수준 3~5에서는 두 버튼을 번갈아 누르는 방법도 선택합니다. 공통 스위치 스캔, 도움, 쉬기, 움직임 줄이기를 지원합니다. 시간 제한·탈락은 없습니다.
- 수업 기록은 기기 로컬에 저장됩니다. 과제별 첫 반응, 시도/오류, 촉진, 신호 버튼 반응 시간과 실제 활동 관찰을 분리하여 CSV로 저장합니다. 화면 신호 반응은 실제 달리기 속도나 운동 기능 평가가 아닙니다. 별 3개는 완료에 대한 참여 보상입니다.
- 완료 뒤 실제 교실 활동을 제안하고 교사는 미관찰/지원받아 참여/독립 참여를 기록합니다. 익명 학생별 프로필은 아직 없어 공동 기기의 기록은 합쳐집니다.
- 활동과 차시는 자체 수업 설계입니다. 국가교육과정 공식 성취기준 달성 판정으로 사용하지 않습니다. 구현: `sports/athletics.js`, `sports/athletics.css`. 점검: `node scripts/athletics-test.mjs`.

GitHub Pages 배포 후 `https://<계정>.github.io/oks-class/` 에서 바로 사용할 수 있습니다.

## 오프라인·앱처럼 설치해서 쓰기
1. 위 주소를 스마트폰/태블릿/PC의 크롬(또는 사파리)으로 한 번 엽니다.
2. 브라우저 메뉴에서 **"홈 화면에 추가"** (iOS: 공유 → 홈 화면에 추가 / Android·PC 크롬: 주소창의 설치 아이콘)를 누릅니다.
3. 한 번 열어두면 서비스 워커가 파일을 저장해두어, 이후에는 인터넷이 없어도 바로 실행됩니다.

## 폴더 구성

### 씽씽별 운동회 경기 업데이트
- 육상 차시의 달리기·속도 조절·허들·계주를 연속 주행 경기로 구성합니다. 리듬 입력이 실제 속도에 영향을 주고, 응원을 모으면 짧은 부스트를 사용할 수 있습니다.
- `기다려 주는 경기`는 입력할 때 이동하며 점프·바통 전달 시 기다립니다. `타이밍 도전`은 자동 주행 중 타이밍을 고릅니다. 수준 1~2와 스캔 모드는 기다려 주는 경기를 사용합니다.
- 함께 완주/순위 도전을 선택할 수 있습니다. 같은 설정의 기기 내 최고 기록과 참여 배지가 저장됩니다. 캐릭터와 의류는 기존 자산을 재사용합니다.
- 경기 시간은 화면 게임 기록입니다. CSV에 경기 방식·리듬·부스트·허들·바통 기록을 함께 내보냅니다.

### 놀이별 마을 (메인)
- `playground/index.html`은 씽씽 별 마을과 같은 틀(지도 배경 + 건물 + 이름표 + 안내자)이에요. 메인 지도에서 전통놀이·전략놀이·보드게임 놀이 마을을 고르면 `?zone=trad|strategy|board` 구역 지도가 열리고, 건물을 누르면 놀이로 가요. 건물 위치·크기는 `hub.js`의 ZONES(광장 가운데 좌표, 1672×941 기준), 그림은 `playground/assets/*.webp`(없으면 임시 건물로 보여요).

### 놀이별 · 3D 체스
- 진입: 놀이별 → 전략놀이 → 3D 체스. 직접 주소는 `playground/chess/`입니다. 모드는 `말 움직임 배우기`(별 모으기), `컴퓨터와 대국`(수준 1~5), `둘이서`입니다.
- 규칙 엔진 `engine.js`(캐슬링·앙파상·프로모션·체크메이트·무승부)는 `node scripts/chess-engine-test.mjs`(perft 포함)로 검증합니다. 컴퓨터 수는 `ai-worker.js`(Web Worker)에서 계산합니다.
- three.js r186을 `vendor/three/`에 복사해 사용합니다(import map 없이 동작하도록 addon의 `from 'three'`를 상대 경로로 바꿈, `vendor/three/README.md` 참고). 말·판은 준비한 chess_set.glb를 줄여 만든 `playground/chess/assets/pieces.glb`, `board.glb`(약 1.3MB)입니다. 검은 말은 흰 말 모델에 검은 재질을 입힙니다.
- 화면 돌리기 잠금, 시점 바꾸기, 갈 수 있는 칸 표시, 힌트, 한 수 물리기를 지원합니다. 장기(한국식)는 별도 파일이 필요합니다.

### 놀이별 · 3D 장기
- 진입: 놀이별 → 전략놀이 → 3D 장기. 직접 주소는 `playground/janggi/`입니다. 모드는 `말 움직임 배우기`(별 모으기), `컴퓨터와 대국`(수준 1~5), `둘이서`이고, 말 글자는 한자(楚·漢·卒/兵·馬·象·車·包·士)입니다. 상차림(왼상·오른상·안상·바깥상)을 고를 수 있습니다.
- 말과 판은 코드로 그립니다(판 무늬·말 글자는 캔버스 그림). 올려 준 `chinese_chess_1.glb`는 중국 장기용이라 쓰지 않았습니다.
- 규칙 엔진 `engine.js`: 궁성 대각선, 포(넘기·포는 못 넘고 못 잡음), 마·상의 막힘, 장군·외통, 한 수 쉬기, 같은 모양 세 번 반복 무승부, 오래 두면 점수(차13 포7 마5 상3 사3 졸2, 한 +1.5)로 판정. 단순화: 두 궁이 마주 보는 수는 금지(빅장 없음). `node scripts/janggi-engine-test.mjs`로 검증합니다. 컴퓨터는 `ai-worker.js`(Web Worker)에서 수를 읽습니다.

### 놀이별 · 3D 다트
- 진입: 놀이별 → 보드게임 → 3D 다트. 직접 주소는 `playground/darts/`입니다. 게임은 `숫자 맞히기`(노란 칸 맞히기, 5라운드), `점수 모으기`(5라운드), `301 줄이기`(수준에 따라 51~301에서 정확히 0, 넘치면 그 라운드는 되돌림)이고, 혼자 또는 둘이서 번갈아 합니다.
- 조준은 `자동 조준`(빨간 동그라미가 움직일 때 화면이나 던지기 단추를 누름)과 `직접 누르기`(판을 누른 채 겨냥하고 떼면 던짐, 터치는 손가락 위쪽에 조준점이 보임)를 고를 수 있고, 게임 중에도 바꿀 수 있습니다. 수준 1~5는 조준점 속도와 직접 누르기의 흔들림 크기를 정합니다.
- 다트판은 준비한 `low-poly_dart_board.glb`를 그대로 쓰고, 다트는 코드로 만든 모양입니다. 점수 칸 반지름(불 0.041, 바깥 불 0.10, 트리플 0.445~0.48, 더블 0.82~0.857)은 모델의 철사 위치를 직접 재어 정했습니다.

- **미술 감상 놀이 묶음**: `games/match/`(그림 짝 찾기, 3~10쌍), `games/look/`(그림 속 색 찾기: 그림 픽셀을 세어 가장 많은 색·따뜻한/차가운 색을 묻습니다), `worksheet/puzzle.html`(오려 붙이는 종이 퍼즐 학습지). 세 놀이와 그림 퍼즐은 `games/puzzle/images.js`의 그림 목록을 함께 씁니다. **명화는 `art/masters/`에 파일을 넣고 `masters.js`에 한 줄 적으면 자동으로 섞여 나옵니다**(저작권이 끝난 작품만). 그림 퍼즐은 최근 결과로 조각 수를 추천하고, '대신 놓아 주기'는 도움 기록(hand)으로 남습니다.
- **미술 표현·체험 놀이**: `games/myface/`(나를 만들어요: 코드로 그린 SVG 부품을 골라 자화상을 조립, 완성하면 작품 전시관 저장소 `oks-class-gallery-v1`에 그림으로 저장), `games/dots/`(점 잇기: 꼭짓점 목록으로 수준별 점 수 조절), `games/senses/`(`?mode=touch` 느낌 짝짓기 · `?mode=sign` 생활 그림문자). 정식 차시 연결은 `play/play.js`의 `EXTRA`, 공방·미술관 링크는 `space/data.js`.

## 놀이별 · 주차장 탈출 (러시아워)
- 진입: 놀이별 → 보드게임 놀이 마을(6칸 지도) → 주차장 탈출. 직접 주소는 `playground/rushhour/`입니다.
- 규칙: 6×6 주차장에서 빨간 차를 오른쪽 출구로 내보냅니다. 차는 앞뒤로만 움직이고, 한 대를 몇 칸 옮겨도 한 번으로 셉니다.
- 조작: 차를 끌어서 옮기거나, 차를 누르면 나오는 초록 동그라미를 누릅니다. 되돌리기·힌트(풀이 프로그램이 다음 한 수를 알려 줌)·다시 하기가 있습니다.
- 모드: `퍼즐`(최소 횟수에 가까울수록 별 3개), `횟수 도전`(최소 횟수 + 여유 안에 성공). 수준 1~5, 수준마다 문제 30개(모두 150개), 진행 기록은 브라우저에 저장됩니다.
- 구성: `engine.js`(규칙·풀이), `puzzles.js`(만들어진 문제), `rushhour.js`(three.js 화면). 차는 코드로 만든 장난감 자동차입니다.
- 시점: 빈 곳을 끌면 360도로 돌려 볼 수 있고, 두 손가락(또는 마우스 휠)으로 확대·축소, 🧭 시점 단추로 처음 모습으로 돌아옵니다.
- 문제 만들기: `SEED=1 WANT=30,30,30,30,30 T1=240000 T2=760000 OUT=a.json node scripts/rush-gen.mjs`를 여러 개 돌린 뒤 `node scripts/rush-merge.mjs a.json b.json`(약 17분, 풀이 프로그램으로 최소 횟수 확인), 검증: `node scripts/rush-test.mjs`.
- 보드게임 지도는 6칸(다트·볼링·주차장 탈출 + 우주 도시 건설 및 준비 중 2칸)입니다.
