# 햇살 농장 전용 3D 동물 이미지

코드는 아래 파일이 존재하면 자동으로 우선 사용하고, 등록되기 전에는 기존 `art/stickers/`의 귀여운 동물을 사용합니다.

- `rabbit.webp`: 사용자가 제공한 밀짚모자·청색 멜빵 토끼 농부
- `cat.webp`: 사용자가 제공한 체크무늬 앞치마 고양이 손님
- `panda.webp`: 사용자가 제공한 밀짚모자·청색 멜빵 판다 손님
- `monkey.webp`: 사용자가 제공한 사파리 모자 원숭이 손님

**업로드 대상:** `fumon1218/oks-class`의 기본 브랜치 `main`, 경로 `art/farm/v4/`.

원본 채팅 업로드 PNG에서 배경을 제거하고 최장 960px WebP로 최적화한 4개 이미지가 ZIP 패키지로 준비되어 있습니다. GitHub의 Upload files 화면에 ZIP 파일 **자체를 업로드하면 안 됩니다.** ZIP을 풀고 4개 `.webp` 파일을 선택해 업로드해야 합니다.

교실 기본 장면은 실제 화분(`plot.png`)을 모든 상태에 공유하고, 바구니는 동일한 3D 바구니 PNG 앞/뒤 사이에 작물을 배치하므로 이 네 파일 업로드 여부와 무관하게 이미 기능 개선이 적용되어 있습니다.
