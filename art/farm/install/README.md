# 햇살 농장 — 사용자 개별 객체 52종 자동 설치

이 폴더는 최신 농장 시안의 **실제 개별 3D 그림과 게임 코드**를 ZIP 파일 하나로 설치하는 업로드 전용 폴더입니다.

1. ChatGPT가 제공하는 **farm_v8_install.zip**을 다운로드합니다. 압축을 풀지 마세요.
2. [이 폴더의 GitHub 업로드 화면](https://github.com/fumon1218/oks-class/upload/main/art/farm/install)에 **farm_v8_install.zip 파일 하나만** 올리고 Commit changes를 누릅니다.
3. [GitHub Actions의 Install illustrated farm v8](https://github.com/fumon1218/oks-class/actions) 실행이 성공하면 수학 교실의 공개 링크가 새 **minigames/farm-v8/index.html**을 가리킵니다. Pages 배포가 끝난 뒤 [새 농장 실행](https://fumon1218.github.io/oks-class/minigames/farm-v8/index.html)에서 확인하세요.

이 ZIP에는 이름 변경 없이 분류한 원본 농장 이미지에서 최적화한 **52개 WebP 파일과 새 게임 HTML/CSS/JS**가 포함됩니다. 실제로 각각 분리된 화분, 성장 작물, 손님, 바구니 앞면/뒷면, 버튼과 온실 배경을 사용하는 설계입니다. ZIP이 검증되지 않으면 기존 운영 게임은 변경되지 않습니다.

새 게임은 기존 농장 로컬 저장 데이터를 지우지 않습니다. 최초 실행 시 기존 코인·별·배달 횟수를 참조하고, 새 버전은 별도 저장 키를 사용하므로 이전 버전으로 돌아갈 수 있습니다. 기존 v3 게임 파일은 삭제되지 않습니다.

문제가 생기면 [Actions 로그](https://github.com/fumon1218/oks-class/actions)를 확인해주세요. ZIP을 풀어서 개별 파일을 업로드할 필요는 없습니다.
