# 선명한 봄 마을 실제 이미지 적용

이 브랜치의 코드는 사용자 제공 1536×1024 산뜻한 봄 바닷가 마을 원본을 대상으로 제작되었습니다.
코드에서 요구하는 실제 파일 경로: `art/scenes/town_spring_hd.webp`.

## 파일 등록
1. 수업 자료를 제작하던 채팅에서 제공받은 `town_spring_hd.webp` 파일(1536×1024, 고품질)을 저장합니다.
2. GitHub `fumon1218/oks-class` 저장소의 `art/scenes/` 폴더에 **정확히 같은 파일명**으로 업로드합니다.
3. 저장소 기본 브랜치의 `art/scenes/town_spring_hd.webp`가 실제로 존재하고 이미지가 정상 표시되는지 확인합니다.

## 이번 코드에 포함된 처리
- 앱이 처음 실행되면 이전 날짜별 랜덤 설정보다 새 봄 마을을 우선 표시합니다.
- 학생·교사가 계절 버튼을 직접 누른 경우에만 해당 날짜 동안 다른 계절을 보여 줍니다.
- 봄 마을에 보이는 8개 건물(미술, 과학, 국어, 음악, 체육, 우주, 사회, 수학)에 터치 좌표를 맞춥니다. 책 모양의 국어 도서관에 다른 이야기방 표식은 겹치지 않게 숨깁니다.
- 서비스 워커는 **파일이 업로드되기 전의 404 오류를 저장하지 않으며**, 파일 등록 후 온라인 재접속 시 다운로드해 오프라인 캐시로 보존합니다.
- 이미지가 없어도 기존 봄 배경을 보여 주어 학생 화면이 깨지지 않도록 합니다.

## 확인 범위
GitHub 소스 업데이트/자동 정적 검사는 업로드 전에도 진행할 수 있지만, 실제 새 마을의 배포·선명도·태블릿 클릭 위치 검사는 **이미지 파일이 원격 저장소에 존재할 때**만 완료 처리합니다.
