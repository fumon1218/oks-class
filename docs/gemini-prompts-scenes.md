# 제미나이 그림 프롬프트 — 차시 장면(게임 공간) 15종

> 이 30장은 이제 **그림 작업판**(`docs/image-prompts.html`, `docs/image-prompts-v2.md`)의 2순위 「차시 게임 장면」에 함께 들어 있어요. 작업판에서 복사해 쓰시면 됩니다.

차시 게임 위쪽 **장면 띠**와 게임판 배경, 한 판마다 하나씩 생기는 **조각** 그림입니다.
그림이 오기 전까지는 이미 있는 그림으로 대신 보여 주고 있어요. 받으면 `art/scene/`에 넣고 바로 바뀝니다.

## 공통 규칙 (모든 프롬프트 앞에 붙여 주세요)

```
Cute 3D cartoon illustration for a children's special-education learning game, soft rounded clay-like shapes, glossy Pixar-style rendering, warm soft daylight, bright pastel colors, cozy and friendly, very clean and uncluttered, no text, no letters, no numbers, no logos, no watermark.
```

- **배경**: 가로 16:9 (1600×900 이상). 아래쪽 1/3과 가운데는 **비워 두기**(카드가 올라가요). 사람·동물 캐릭터 **넣지 않기**(동물 안내자는 따로 있어요).
- **조각**: 정사각형 1:1 (512×512 이상), **투명 배경 PNG**(안 되면 흰 배경도 괜찮아요 — 제가 지울게요), 물건 하나만 가운데 크게.
- **파일 이름**을 아래 표 그대로 해 주세요 (예: `forest.png`, `forest_piece.png`). 여러 장이면 zip으로 한 번에 주셔도 돼요.
